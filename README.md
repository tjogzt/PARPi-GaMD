# PARPi-GaMD

Analysis pipeline for: **"Same Pocket, Two Fates: GaMD Quantifies How PARP1 Inhibitors Differentially Encode HD Allostery to Control DNA Trapping"**

## Structure
- `scripts/` — PMF reconstruction, convergence, RMSF, DCCM, PCA
- `data/replicates/` — Processed PMF profiles per replicate
- `figures/` — Source files for manuscript figures

## Requirements
Python 3.10+, mdtraj, numpy, scipy, PyReweighting
